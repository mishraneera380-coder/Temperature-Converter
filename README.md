# Temperature Converter Website

A modern, interactive temperature converter built with HTML, CSS, and JavaScript.  
Designed to provide real-time conversion between Celsius, Fahrenheit, and Kelvin with input validation and a clean, responsive UI.

---

## Features
- Numeric input field with validation (rejects non-numeric input).
- Unit selector (Celsius / Fahrenheit / Kelvin).
- Auto-conversion showing all output units simultaneously.
- Convert button to trigger calculations.
- Result display area with correct unit labels.
- Edge case handling for absolute zero violations (e.g., below −273.15°C).
- Clean, centered UI layout with clear labels.

---

## Technologies Used
- **HTML5** → Structure & semantic markup  
- **CSS3** → Styling, layout, responsiveness (Flexbox, Media Queries)  
- **JavaScript (Vanilla)** → Conversion logic & input validation
